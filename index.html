Claude Code: the (model, effort) grid

3 models × 5 effort levels = 15 cells. Each cell states whether the pair is a useful combination, in what way, and what evidence supports that. Click a cell in the overview. Only that cell's card is shown, and the other cells dim.

Claude skipped a file, a test, or stopped early? It did not try hard enough. Raise effort.
Claude had the context, tried, and was still wrong? It did not know enough. Use a more capable model.

Overview

Sweet spot: the combination a source names as a default or a first choice for a kind of work. Useful: a source supports a clear use. Conditional: works only if a stated condition holds. The card's "Use it when" line states the condition. Unproven: no source measures it. Only a general rule applies. The verdict is my synthesis of the sources. The evidence line on each card shows what the sources say and what I inferred.
Evidence labels. Advice in words: the source recommends a setting but gives no test result. Test result: the source reports a measured result, such as 1/5 → 5/5 passes. My inference: no source says it. Letters (A, B, C, D1…D6, S, L, K) link to the source.
